# 01 — Propuesta académica

## Título provisional

**Diseño e implantación de una infraestructura informática segura para alojar y administrar Mi Apiario.**

## Contexto

Mi Apiario es una aplicación web progresiva (PWA) orientada a la gestión apícola. Este proyecto de ASIR utilizará la aplicación como caso práctico para diseñar y administrar una infraestructura informática independiente.

El objeto principal de evaluación no será desarrollar de nuevo la aplicación, sino demostrar competencias de administración de sistemas, redes, servicios, seguridad, monitorización, automatización y continuidad.

## Objetivo general

Diseñar, desplegar, administrar y documentar una infraestructura basada en Linux que permita alojar una versión de Mi Apiario y proporcionar servicios de red, acceso seguro, supervisión, mantenimiento y recuperación ante incidencias.

## Objetivos específicos

1. Analizar las necesidades técnicas y definir requisitos verificables.
2. Diseñar una topología de red segmentada y un plan de direccionamiento.
3. Instalar y configurar Ubuntu Server.
4. Administrar usuarios, permisos, acceso remoto y actualizaciones.
5. Desplegar la aplicación web mediante contenedores y un servidor web inverso.
6. Configurar controles de seguridad y reducir la superficie de exposición.
7. Implantar monitorización de disponibilidad y estado de servicios.
8. Automatizar tareas de mantenimiento y copias de seguridad.
9. Realizar pruebas de funcionamiento, seguridad y restauración.
10. Elaborar documentación técnica y procedimientos de operación.

## Alcance

### Incluido

- Laboratorio virtualizado.
- Diseño y simulación de red.
- Servidor Linux.
- Despliegue web independiente.
- Docker Compose y Nginx.
- Seguridad básica del sistema y del servicio.
- Monitorización.
- Copias de configuración y despliegue.
- Automatización mediante scripts.
- Pruebas y documentación.

### Excluido inicialmente

- Reescritura de Mi Apiario.
- Modificación de su esquema de datos o migraciones.
- Sincronización centralizada de datos apícolas.
- Almacenamiento remoto de datos personales de usuarios.
- Kubernetes y clúster de alta disponibilidad.
- Servicios cloud de pago.
- Exposición pública a Internet hasta completar revisión de seguridad y aprobación del tutor.

## Resultados esperados

- Infraestructura desplegable y documentada.
- Aplicación accesible en el entorno de laboratorio.
- Red y reglas de acceso verificadas.
- Servicios monitorizados.
- Copias de seguridad ejecutadas y restauración demostrada.
- Scripts revisados y probados.
- Memoria técnica y evidencias para la defensa.

## Condiciones de aprobación

La propuesta es provisional y deberá adaptarse a la guía, rúbrica, calendario y resultados de aprendizaje que establezca Digitech FP.
